# life-guide 发布文案

## 短版

AI 让得到一个答案变快了，但找到真正有用的信息，仍然需要知道去哪里搜、搜什么、怎样追到源头。

`life-guide` 是一个通用 Agent Skill：它先识别会改变答案的条件，再扩大候选空间，查成熟工具和不同路线，核对官方原文与现实反馈，最后给出有依据、有取舍、能执行的下一步。

## 完整版

很多问题难的不是“从几个选项里选一个”，而是你一开始看到的选项就太少。

想做点小生意，AI 可能只想到奶茶、咖啡和服装店；但真正值得看的，可能还有原料、耗材、设备、维修、配送、软件、代运营和上游供应链。想模仿一个网站，也可能在写代码之前就已经存在成熟工具和商业链路。

AI 能很快给出一个看似完整的答案，却不一定带你走过正确的检索路径。高质量调查通常要分工：搜索引擎负责找到关键词和入口；官方文档、法规、源码和统计资料负责确认事实；Reddit、X、微博、小红书负责发现真实讨论、失败经历和最新信号；YouTube 负责观察具体操作、版本差异和实际体验；关键结论最后仍要回到能直接支持它的原始来源。

`life-guide` 就是把这条路径变成可复用的 Skill。它帮助 AI：

- 先问清会改变判断的目标、现状和约束；
- 找到用户还没看见的不同路线和参与位置；
- 区分事实、用户陈述、推断和未知；
- 给出来源、日期、适用范围和证据状态；
- 展示机会成本、相对耗时、稳健性和最小验证；
- 在证据不足时明确收窄结论，而不是假装确定。

它不保证穷尽所有可能，也不把点赞、Star、热度或一条经验帖当成事实。它要减少的，是“答案看起来完整，但关键选项和证据根本没被找到”的信息差。

## 一句话定位

**让 AI 不只回答你看见的问题，还沿着搜索、核验和现实反馈，把你没看见的路线找出来。**

> 本文是项目原创改写文案，借鉴了“信息检索能力比单纯辨别真假更稀缺”的公开讨论思路，不是对他人原文的逐字转载。
