# 30 秒抖音演示方案

## 定位

用一个问题展示 life-guide 的差异：它会先扩大候选空间，再核验依据和风险，不只在用户已经想到的几个选项里排序。

本稿是产品行为演示，不是奶茶行业调查，也不证明任何路线适合每个人。

## 分镜

| 时间 | 画面 | 字幕与旁白 |
|---|---|---|
| 0–3 秒 | 输入“我想做点小生意，但只想到奶茶店” | “你问 AI 做生意，它是不是总让你选奶茶、咖啡或服装店？” |
| 3–8 秒 | 热门选项旁出现“选项太窄” | “难点可能不是不会选，而是没看到真正能选的东西。” |
| 8–17 秒 | 思维导图展开原料、制冰设备、耗材、维修、租赁、二手、代运营、档口、上游、试验、暂缓 | “life-guide 会继续找上游、设备、配套、替代路线和低成本试验。” |
| 17–24 秒 | 出现“依据 / 未知 / 最坏分支 / 下一步”四张卡片 | “然后区分哪些是事实，哪些还没核实，最坏会发生什么，以及下一步怎么验证。” |
| 24–30 秒 | 出现 life-guide 和 GitHub 地址 | “它不会替你决定人生，但会帮你先看见更多路，再决定走哪一条。” |

## 片尾

`life-guide` 让 AI 先找隐藏选项、核验依据、比较代价，再给出下一步。

仓库：`github.com/shk825620-dot/life-guide`

## 给 DSH 自媒体插件的提示词

```text
制作一条约 30 秒的中文抖音竖屏短视频，画幅 9:16，普通话配音，简体中文字幕。

主题是：AI 给建议之前，先帮用户找出没看到的选项。

案例是：用户说“我想做点小生意，但只想到奶茶店”。展示 life-guide 继续寻找原料、制冰设备、杯子耗材、维修、租赁、二手、代运营、档口、上游供应、配套服务、低成本试验和暂缓路线。随后展示依据、未知、最坏分支和最低成本下一步。

前 3 秒必须出现问题和冲突，中间用简洁思维导图展示候选扩展，最后 3 秒显示 life-guide 和 https://github.com/shk825620-dot/life-guide。

这是产品行为演示，不是奶茶行业调查。不要编造价格、销量、利润、法规、用户数据、搜索结果、GitHub Stars 或平台测试结果。不要声称适用于所有 AI、一定找到最优解或已经跨平台实测。没有真实检索时，不要制作伪造的搜索页面或来源截图。
```

## 发布前检查

- [ ] 没有伪造搜索结果、价格、法规或用户数据
- [ ] 没有声称一定找到最优解或跨平台已验证
- [ ] GitHub 地址准确
- [ ] 片尾至少停留 3 秒
- [ ] 视频时长接近 30 秒
