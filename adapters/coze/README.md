# 扣子 Coze 适配说明

## 当前判断

扣子官方文档明确支持用 Skill、MCP 和 Panel 扩展 Agent，并可创建不包含 Panel 的能力插件。`life-guide` 适合先按“纯 Skill”或“Skill + 搜索/MCP”能力插件移植。

建议映射：

- Skill：放入触发范围、问题澄清、候选扩展、证据核验、比较和输出合同。
- MCP/插件：只连接实际需要的搜索、文件或业务数据；由用户单独授权。
- Panel：当前不需要，除非后续要展示证据表、候选地图或决策日志。

## 未验证

本项目未在扣子控制台实际创建、发布或运行插件；字段映射、技能加载、工具调用、权限确认和多轮行为均未验证。不能把官方平台支持 Skill 写成该 Skill 已经在扣子中可用。

## 建议验收

用三个任务验收：候选隐藏路线、官方规则核验、截止时间下的高风险决策。分别记录是否触发、是否调用正确工具、是否展示来源/日期/未核实状态、是否在工具不可用时降级。
