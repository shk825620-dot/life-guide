# 豆包 Agent / 工作任务适配说明

## 当前判断

豆包的公开产品资料显示，工作任务体系支持“技能、连接器、工作伙伴/小队”等能力组件；本项目可以按“自定义技能/能力插件”思路移植。当前没有证据证明豆包客户端可以直接识别本仓库的 Agent Skills 目录、`agents/openai.yaml` 或相同的自动发现字段。

因此本适配器只承诺**内容映射方案**：

- 把 `skills/life-guide/SKILL.md` 的触发范围、首要准则和主流程转成豆包自定义技能的说明与执行要求。
- 把 `references/` 中的能力预检、输出合同、检索、候选扩展、测算和监督规则按需放入技能资料或插件知识。
- 需要联网搜索、文件读取、计算或第三方服务时，使用豆包已启用的连接器；没有连接器就按 Skill 的降级规则标“未核实”。
- 涉及登录、付款、写入或敏感资料时，仍由用户在豆包界面明确授权；不自动绕过验证码、限流或风控。

## 未验证

豆包客户端/工作任务中的导入字段、自动触发、参考文件按需读取、工具调用、长任务恢复和实际回答质量均未在本项目中实测。不要把“有技能组件”写成“已兼容本仓库标准包”。

## 建议验收

1. 在豆包中创建一个不带 Panel 的自定义技能或能力插件。
2. 用“我想做小生意，但只想到奶茶店”测试是否触发候选扩展。
3. 用一个法规题测试来源、日期、适用范围和未核实边界。
4. 关闭搜索/连接器后复测，确认它不会伪造已检索。
5. 记录完整输入、实际调用的连接器和输出，才能升级为实测兼容。
