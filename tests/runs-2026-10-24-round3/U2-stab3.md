# 转行数据分析：给你的路线建议

先说结论：你的条件比你想的有利——用过 Excel、每天能挤 1-2 小时、几千块预算，走「自学 + 在现公司先接触数据」这条路的成本完全够。但也要说实话：30 岁、无编程经验、行政背景，直接跳槽去和大量应届生竞争「数据分析师」岗位会很吃力。所以这份路线的关键不是「学什么软件」，而是**怎么把你现在的贸易行业经验当成跳板**，让学的每一样东西都尽量落在真实数据上。

下面分五部分：三件容易走弯路的事、具体学习路线、钱怎么花、风险和止损点、本周就能做的事。最后有几个问题，你补上之后，求职策略那部分可以收窄成更确定的版本。

## 一、先说三件容易被忽略的事

**1. 你的预算足够，甚至花不完——「几千块」最容易花错地方。**
这条路线的主干（Excel 进阶、SQL、统计基础、BI 工具、Python 入门）用免费资源就能走完，真正要投入的是大约 9-12 个月的时间（这是推断，不是保证；参照 DataCamp 给零基础者的 12 个月路线图，见文末来源）。市面上「数据分析就业班」普遍报价 1.5 万-3.5 万元，超出你预算好几倍，而且「包就业」多为营销话术，还有学员被诱导贷款交学费（培训贷）的公开案例（来源见文末）。你的几千块只需要花在刀刃上：一两本书，加一门口碑可查、先试听过再买的线上课，足够了。

**2. 「数据分析」不是一个岗位，而是一簇岗位，门槛和打法差别很大。**
- 数据分析师 / 商业分析师：竞争最激烈，应届生供给大，对学历和公司背景敏感；
- 数据运营、经营分析、BI 报表、供应链/销售分析：更贴近业务，是转行者更现实的入口；
- 你所在的贸易行业本身就是差异化优势：懂报关、单证、库存、汇率、客户台账的人来做贸易公司的数据，比一个只会工具、不懂业务的应届生值钱。

对 30 岁、无经验的人来说，最可行的路径通常不是「跳出去从零开始」，而是「在现在这个行业里，往带数据的岗位挪一步」，先积累一段真实的数据工作经验，再决定要不要往外跳。

**3. 你现在的工作可能就是最好的入口。**
贸易公司里到处是真实业务数据：销售台账、订单、库存、客户、回款。行政岗位有天然的便利——你完全可以先「把一张没人看的表做成自动汇总的报表」。用真实业务数据做出来的东西，比网课的结课项目在面试或转岗谈判里有说服力得多，而且零成本、不辞职、不冒风险。这是我认为你最该优先走的一条线，比先报任何课都重要。

## 二、学习路线（按每天 1-2 小时排）

主干顺序基本是行业共识：**Excel 进阶 → SQL → 统计基础 + BI 工具 → Python（可后置）**，全程用真实数据练，不要只看课不动手。

| 阶段 | 学什么 | 做什么 | 参考资源（均免费） |
|---|---|---|---|
| 第 0 周 | 自查 Excel 水平 | 会数据透视表和 VLOOKUP 这两样就直接进下一阶段；不会就先补这两样 | B 站免费教程合集 |
| 第 1-2 个月 | Excel 进阶：透视表、VLOOKUP/XLOOKUP、常用函数（SUMIF/COUNTIF 等）、图表 | 挑公司里一张你接触过的表，做一个能自动汇总的报表交给用得上的人 | B 站教程；腾讯云那篇技能清单里的 Excel 部分 |
| 第 2-4 个月 | SQL：查询、多表关联、聚合、分组、子查询 | 每天 1-2 题：先刷完「非技术快速入门」约 50 题，再进阶到基础进阶题单 | 牛客网 SQL 题库（免费在线练习） |
| 第 4-6 个月 | 统计基础（描述统计、对比、漏斗、A/B 测试的概念）+ 一个 BI 工具 | 用公司脱敏数据或公开数据集做 1-2 个可视化分析，发到 Tableau Public 或作为转岗材料 | Power BI Desktop（免费）/ Tableau Public（免费） |
| 第 6-9 个月 | Python 基础 + pandas | 用 Python 处理 Excel 搞不定的数据清洗和批量处理；做出 2-3 个完整分析项目 | B 站教程 + 官方文档 |
| 第 9-12 个月 | 求职 / 转岗准备 | 把项目整理成作品集；对照目标城市 JD 查漏补缺；更新简历 | BOSS 直聘等平台搜真实 JD |

几点说明：

- **SQL 是整条路线里性价比最高的一件事。**几乎所有数据分析类岗位的简历筛选都会看它；而且对没有编程经验的人是最友好的入门——每条语句写完马上能看到结果，反馈即时。时间紧的话，优先保 SQL。
- **Python 可以放到后段。**如果你的目标偏业务侧（数据运营、经营分析），Excel + SQL + BI 已经能覆盖大部分入门岗位的要求；Python 学到「会用 pandas 清洗数据」即可，不必一上来就啃编程，更不必先去学计算机基础。
- **BI 工具选哪个，以你目标城市的招聘要求为准。**国外系有 Power BI（微软，免费）和 Tableau（Public 版免费）；国内公司也常见帆软 FineBI、阿里 Quick BI 等。第 4 个月开始前，去招聘平台数一数目标岗位 JD 里哪个工具出现最多，就学哪个。
- **进度弹性。**上面的排法按每周 7-14 小时算。坚持得好可以压缩到 6-8 个月；中间断了几周，接上继续即可，不要推倒重来。但 SQL 和统计基础不要跳步，这两块跳过的话后面全是虚的。

## 三、钱怎么花（几千块够，而且有富余）

| 项目 | 大致花费 | 必要性 |
|---|---|---|
| 免费主干：B 站教程、牛客刷题、Power BI / Tableau 免费版 | 0 元 | 必走 |
| 1-2 本书（一本 SQL 入门 + 一本统计入门，比如《SQL 必知必会》这类薄书） | 约 100-200 元 | 推荐：书系统性比碎片视频好 |
| 一门口碑可查的线上课（务必先试听） | 几百到一千多元 | 可选：自律性好可以不买 |
| 备用（某个课程会员、数据资源等） | 留几百元 | 备用 |

**明确不建议花的钱**：1.5 万元以上的线下「就业班 / 保 offer 班」。三个理由：一是超出你预算数倍；二是你每天只有 1-2 小时，根本没有时间脱产去上线下班；三是「包就业」承诺的兑现方式（推荐就业、包装简历甚至协助造假）含大量水分，行业里已有不少公开的质疑和维权案例（来源见文末）。

## 四、风险和止损点

- **最大的失败路径不是「学不会」，而是「学完了，但简历上没有任何用数据做成过的事」。**对策已经写进路线里：从第 1 个月起就在公司真实数据上练，每个阶段都留下一件拿得出手的产出。
- **第二条失败路径是半途而废。**每天 1-2 小时要撑大半年，靠意志力不够，要靠短反馈：每 2-3 个月给自己一个看得见的产出（一张自动化报表、刷完一个题库、一个可视化作品），而不是只记「看了多少节课」。
- **改判条件**：如果学到 SQL 阶段（大约第 3-4 个月）你发现自己非常排斥这种和表格、数字打交道的工作方式，那就及时止损——这些技能用在「懂数据的外贸业务 / 运营岗」上同样增值，不必硬挤纯数据岗。这条路不是单行道。

## 五、本周就可以做的三件事（零成本试水）

1. 上牛客网，把 SQL「非技术快速入门」的前 3 题做了（约半小时）。这是成本最低的试水：体会一下「写一条语句、马上看到结果」的感觉，判断自己是否受得了这种工作方式。
2. 列出你在公司接触过或能接触到的 3 张表（订单、库存、客户台账……），挑一张，用透视表回答一个具体问题（比如「上季度哪个品类或客户增长最快」）。做出来的东西就是你作品集的第一件，也可以顺手发给领导——这可能直接打开内部转岗的口子。
3. 打开 BOSS 直聘，搜你所在城市的「数据分析师 / 数据运营」，把前 10 条职位的学历要求和技能要求抄下来。这份清单就是你的学习大纲，比任何攻略都准；哪几样反复出现，哪几样就是重点。

## 需要你补充的四个问题

学习路线本身对下面这些不敏感，上面可以直接照走；但「学成之后怎么跳」取决于它们，答案不同，建议会不同：

1. **学历**：本科还是大专？数据分析岗招聘里本科是主流门槛（有针对上海岗位的统计显示本科约占 83%、大专约 8%；单城市样本，仅供参考，见文末）。如果是大专，主路线会调整为「业务侧切入 + 内部转岗」优先，直接投简历作为备选。
2. **城市**：你在什么城市，愿不愿意为此去一线 / 新一线？一线和新一线的初级数据岗位供给充足；如果是三四线城市，本地岗位可能很少，内部转岗、远程岗位或去相邻城市会成为主要选项。
3. **现公司的情况**：公司里有没有做报表、销售支持、供应链数据的人或岗位？你有没有可能接手一部分这类活？这决定「内部转岗」这条最稳的路走不走得通。
4. **时间预期**：你希望多久换到数据相关的岗位？如果 1 年内想动，内部转岗或数据运营类岗位是主目标；如果能接受 2 年，往纯数据分析师跳的成功把握会更大。

把这四个问题答一下，我可以把上面的路线收成一份针对你情况的确定版，包括具体的投递策略和作品集选题。
