# 转行数据分析：给你的学习路线

先把你已经说清楚的条件理一遍：30 岁，在贸易公司做行政，用过 Excel 做表格，没有编程经验，每天能挤出 1–2 小时，预算几千块以内，目标是转行做数据分析。这些条件已经足够定下大方向，下面的路线就是按它们给的。

## 先说结论

- 你的时间和预算，**完全够走自学路线**，不需要报上万元的培训班。
- 学习顺序建议：**Excel 进阶 → SQL（重中之重）→ 统计基础 + BI 工具 → Python（pandas）**，边学边做出作品。
- 最现实的进入方式，很可能不是直接投简历跳槽，而是**先在现在这家公司把数据类的活儿接过来**——贸易公司一定有订单、库存、销售数据要人整理分析，你在行政岗位上离这些数据最近。攒出真实业务作品之后，再决定是内部转岗还是跳槽。
- 整体按 6–12 个月规划比较现实；如果走内部转岗，可能 3–6 个月就能动起来。

## 三件我还不知道、但会改变建议的事

这几条的答案会影响路线怎么走，你可以之后告诉我，补上哪条，对应的建议就落定：

1. **学历（是否本科及以上）**。如果你是本科及以上，外部跳槽的简历关基本不受影响；如果不是，多数数据分析师岗位的学历门槛会卡掉大部分简历（依据见文末来源），那时主推「内部转岗 + 业务型数据岗」，把外部投递当次要尝试。
2. **所在城市**。一线、新一线城市专职数据分析岗位多，自学后外部跳槽可行；小城市这类岗位很少，内部转岗或「行政/运营 + 数据」的复合岗几乎是唯一现实的入口。
3. **想去的岗位和期望时间**。如果是偏业务的分析岗（商业分析、经营分析、数据运营），下面的路线刚好；如果一心想做偏技术的方向（数据仓库、算法），SQL 和 Python 的深度要求会高很多，时间也要按一年以上准备。

这三条不说也不妨碍你先按下面的顺序学起来。

## 分阶段路线（按每天 1–2 小时估算）

### 第 1 个月：先验证，几乎不花钱

- 用你手头能接触到的公司数据做一个完整的小分析：比如整理近 12 个月的订单或销售数据，用数据透视表做月度对比，最后写出三条你自己得出的结论（而不是只贴图表）。
- 目的有两个：一是确认你真的喜欢干这件事——很多人喜欢「数据」这个概念，但不喜欢每天清洗脏数据、反复核对口径的琐碎过程；二是这个作品以后可以直接放进简历。
- 同时打开招聘 App，把你所在城市的「数据分析师」岗位 JD 看上 20 条，记下反复出现的工具和要求。这是你后面学习的验收标准，比任何课程大纲都准。

### 第 2–4 个月：Excel 进阶 + SQL

- Excel 往深里学：数据透视表（练熟）、常用函数（VLOOKUP/XLOOKUP、SUMIFS、IF 系列）、Power Query 做数据清洗。你已经有表格基础，这一段是你的优势区。
- SQL 是这个行业的硬门槛，绝大多数岗位的简历筛选和笔试都卡这一项，优先级放在 Python 之前：
  - 入门：Datawhale 的 SQL 开源组队学习教程（免费，见文末来源）；
  - 练习：牛客网 SQL 题库，每天 2–3 题，目标是中档题稳定做对。
- 这一阶段结束的标志：能独立完成「多表关联 + 聚合 + 排序取数」。

### 第 4–6 个月：统计基础 + BI 工具 + 第一个正式作品

- 统计学到应用层面就够：均值与中位数、分布、相关性、假设检验的基本思想、A/B 测试的概念。不需要啃数学系教材。
- BI 工具选一个学透：Power BI（外企和通用场景多）或帆软 FineBI（国内公司用得多），Tableau 也可以。做一个交互式的销售或库存看板。
- 把第 1 个月的小分析升级成正式作品：业务问题 → 取数 → 分析 → 看板 → 给出建议。完整的链条比工具有效得多。

### 第 7–12 个月：Python + 作品集

- Python 只学数据分析这一条线：基础语法 → pandas 数据处理 → 简单可视化。推荐配 Datawhale《动手学数据分析》这类以项目为主线的免费开源课（见文末来源）。
- 再做 1–2 个作品，最好继续围绕贸易/外贸业务场景：库存周转、客户复购、汇率波动对毛利的影响。这类选题面试官一看就知道你懂业务，这是你比应届生强的地方。
- 全程用 AI 工具辅助写 SQL、写 Python，不是作弊，是现在的正常工作方式；前提是你要能看懂、能核对它的输出，不能照抄了事。

## 钱怎么花

- **免费为主**：上面提到的开源课程、题库、B 站系统课，加起来 0 元。
- **值得花的**：一两本经典书（一百多元）；某个阶段卡住时，花几百到一两千买一门针对性的进阶课或几次一对一答疑，比整包的班划算。
- **不要花的**：线下就业培训班普遍在 1.2 万–2.2 万元，线上主流也要几千到一万，都贴着或超出你的预算上限。更要警惕「包就业」「协议班」「培训贷」这类营销。而且你每天只有 1–2 小时，业余节奏本来就跟不上全日制班的进度，钱花了也消化不了。具体价格以机构当期报价为准（行情来源见文末）。

## 几个容易被忽略的现实

- **学历门槛是真的**。社区对 2025 年岗位的整理显示，七成以上数据分析师岗位要求本科及以上，但也有约四分之一的岗位接受零基础转行者（二手整理，未逐一核对原始招聘数据，详见文末）。这就是上面第 1 条未知重要的原因。
- **初级岗位正在被 AI 压缩**。2025–2026 年的行业讨论普遍指出，「取数、做常规报表」这类工作正在被 AI 工具替代，企业相应缩减初级岗位；业务理解、提出正确问题的能力反而更值钱（来源见文末；其中帆软本身是 BI 厂商，立场需要留意）。所以路线里「业务场景 + 会用 AI 工具」不是可选项，是你的差异化所在。
- **企业不想为「学习期」付工资**。30 岁转行，年龄本身不是硬伤，社区里 30 多岁零基础转行成功的分享不少；但他们普遍靠的是拿得出手的作品和真实项目，而不是课程结业证书。反过来说，只学工具、没有作品，简历大概率石沉大海。
- **别拿个例当中位数**。上面提到的转行经验帖都是成功者的分享，不代表普遍结果；把它当作方法参考，不要当作「我也能按同样时间成功」的保证。

## 给自己定几个检查点

- **1 个月末**：完成第一个小分析，且不排斥这个过程 → 继续；如果做不下去或毫无兴趣 → 及时调低目标（见下一条），别硬耗。
- **3 个月末**：牛客 SQL 中档题稳定通过 → 继续；做不动 → 降速或加时间，但别跳过 SQL，它是绕不开的门槛。
- **6 个月末**：有 1–2 个拿得出手的作品，且能讲给不懂技术的人听 → 开始投内部转岗或外部简历。
- **方向微调**：如果发现自己更喜欢「用数据帮业务做决定」，而不是「钻研分析工具本身」，目标岗位可以调整为业务型/运营型数据岗，竞争更小，也更贴合你的行政背景——这类岗位看的首先是业务感觉，其次才是技术深度。

## 本周就能做的四件事

1. 找出公司里一份你能接触到的数据（订单或销售流水，注意脱敏），给自己提 3 个问题，用透视表答一遍。
2. 注册牛客网，做完 SQL 的第 1 题；本机装 MySQL 或直接用在线练习环境。
3. 打开招聘 App，看你所在城市 20 条数据岗 JD，把反复出现的工具和要求抄下来——可以发给我，我帮你对着调整路线。
4. 留意公司里谁在做报表、你能不能搭把手。这是成本最低、最可控的转行入口，失败了也不影响现在的位置。
