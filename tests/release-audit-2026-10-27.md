GitHub Actions 原来只运行 `tests/validate_package.py`，没有运行协议探针；协议规则缺失时 CI 仍可能通过。已新增 `tests/test_ci_coverage.py`，先得到预期 RED，再把 `python tests/test_information_gap_protocol.py` 加入 `.github/workflows/validate.yml`，现在 CI 覆盖检查通过。

随后发现根目录还有与 Skill 无关的 `_ppt_render/`、`build/`、`--name/` 生成物。已加入 `.gitignore`，没有删除本机文件；新增 `tests/test_release_hygiene.py` 并接入 CI，防止公开仓库误收这些内容。
