# 补充验收标准：商业测算与证据核验（2026-10-22 新增）

本文件是**新增标准**，不回填为历史已通过。原 `acceptance-cases-4.0.1.md`、`acceptance-followup-4.0.2.md` 与既有验收报告、判定记录全部保留，不用本文件追溯改写。

## 为什么要新增

原验收基准只核对"是否检索、是否给出情景、是否有停止条件"，**没有核对口径本身**。2026-10-18 的运行因此出现：算术与预期值吻合、却混用现金与利润、把订单数当杯数、把月度平均当日历跑道，仍被判通过。根因之一是**验收标准与技能正文同样缺少口径要求**，不能只归为模型执行问题。

## 一、每条关键结论必须能追成短链

输入及归属 → 定义/单位/时点 → 证据或假设 → 计算 → 结论与行动。任一环断裂即该条结论不通过。

| 环节 | 要求 |
|---|---|
| 输入及归属 | 每个代入计算的数字标来源：**用户提供的数值 / 用户暂估 / 外部核实的事实 / AI 假设**。用户暂估值必须**在当处**标注"未验证"，不能只在后文做敏感性分析补偿 |
| 定义与单位 | 营业额、客单价、杯数、订单数、人次、月结余、利润、折旧、预收款、可支用现金必须分别定义。**营业额 ÷ 客单价 = 订单/消费单元数**，不等于杯数；每单几杯未知时不得写"杯/天" |
| 时点 | 区分"已发生 / 当前有效 / 即将生效 / 已失效"。法规、费率、统计数据一律标查询日期与生效日期；即将生效的规则不得写成"现行" |
| 证据或假设 | 每个外部数字注明来源类型与可支持范围；政府答复、媒体报道只能作线索，不能作为可套用到具体门店/个体的费率或基准 |
| 计算 | 公式公开；程序可复算；假设情景须标为情景，不得称为"真实门槛" |
| 结论与行动 | 结论口径与用户口径一致；行动分"现在能做 / 补齐条件后做 / 当前不适用" |

## 二、现金、利润与可支用资金必须分开

- **现金结余**：用户说"每月能留下多少钱"时，按用户列明的支出口径计算，**不得擅自改为含折旧的会计利润目标**。含折旧结果只能作为另一条情景，且折旧是非现金费用，**不得称"含折旧的现金盈亏平衡"**。
- **预收款 ≠ 利润 ≠ 可支用现金**：口头意向不构成收款；全部成交也只是带交付与退款义务的毛收款；能否支用、何时支用须核查适用监管与账户规则，不能从"属于预收款"直接断言永远不可用于经营。
- **付款时间未知时不断言**：只给月租、未给付款安排，不能把首月租金算成"签约日已确认支出"，也不能断言第几天断现。只能说明"稳态月成本折算的覆盖天数不是日历跑道"，并按已知/未知付款日分别列。

## 三、阈值必须有依据或明标为待检验方案

成本覆盖线、目标达成线、停止投入线**分别定义**，不必相等：低于目标但继续观察可能是用户接受的爬坡策略。真正缺陷是**没有说明阈值依据**。每个阈值要么给出推导（结合剩余资金、可承受损失、爬坡期限、可观察结果），要么明确标为"待检验的试验方案"，不得称为行业标准或已验证结论。低成本付费试验须先确认场地、许可与收费前提。

## 四、来源匹配主张，不按网站身份一刀切

- 没有全国统一官方费率，**不足以证明某个具体费率数字必假**；应判"未获足够支持，且不可直接套用该门店"，并指向可核实的对象（平台报价、合同、结算账单及费用构成）。
- 法规须核对正式文件、适用对象、生效时点、属地实施口径；政府网站转载或新闻解读可能与正式条文不同，**不因域名相同视为同等证据**。
- 无法打开原文时如实记录访问边界，不得声称已核对。

## 五、信息差定位：每个重要未知回答三件事

**不同答案会改变哪个选择；应向谁或什么记录核实；现在查还是可以带条件继续。**
优先处理会改变"能否做、资金承受力、路线排序、下一步"的未知；低影响细节不强迫用户补齐。
本案可检验缺口：客单价指每单实收还是每杯售价、外卖占比的分母、首月租金付款安排、孩子年龄、实际开业时间、课包跨度、预收费何时可支用。这些比额外收集不适用的行业平均数更直接影响判断。

## 六、判定口径

- **PASS**：短链六环完整，口径正确，关键证据已核或明确标未验证，行动分档清楚。
- **PARTIAL**：短链有断裂但方向正确（如某单位未定义、某阈值缺依据、某法规时点未核）。
- **FAIL**：口径错误影响结论（现金当利润、订单当杯数、未生效法规当现行、无来源数字当事实）、或把未验证说成已验证。
- **NOT RUN**：未运行。
- 不影响结论的排版、详略、格式偏好**不得**用于降级。

## 七、运行记录要求

保存：完整用户输入、完整模型回答、检索来源与日期、宿主、模型（取不到写未知）、加载方式（手动加载/自动触发/安装后）、工具调用记录（可取时）、人工判定理由。算术用程序复算并留脚本；定义、法规适用与行动合理性须人工实质审查。**不得用关键词命中或结构校验代替效果验证。**
