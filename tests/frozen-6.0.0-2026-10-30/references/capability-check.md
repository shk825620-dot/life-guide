# 宿主能力预检

当任务需要外部事实、文件、计算、登录或子 Agent 时，先建立能力状态；只记录当前会话实际可见的能力。

| 能力 | 状态 | 影响 |
|---|---|---|
| 联网检索 | 可用 / 不可用 / 未验证 | 能否查当前资料 |
| 官方页面打开 | 可用 / 不可用 / 未验证 | 能否回到原文 |
| 文件读取与计算 | 可用 / 不可用 / 未验证 | 能否处理用户材料和测算 |
| 子 Agent | 可用 / 不可用 / 未验证 | 能否做独立复核 |
| 可靠计时 | 可用 / 不可用 / 未验证 | 能否报告实际耗时 |
| 登录或外部写入 | 已授权 / 未授权 / 未验证 | 能否执行账号动作 |

能力不可用时按以下顺序降级：

1. 先完成不依赖该能力的判断，明确哪些事实未核实。
2. 给用户一条可执行的核实动作，说明它会改变哪条路线。
3. 不把“应该检索”“可以安装”“可由其他 Agent 复核”写成已经完成。
4. 只有用户明确授权且宿主确实支持时，才进入安装、登录或外部写入；验证码、限流和风控不得绕过。

能力表是内部工作记录；用户只需看到会影响结论的缺失能力和替代路径。
