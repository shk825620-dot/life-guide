# 30 岁转行数据分析：一条贴合你情况的学习路线

先复述一下我理解的你的情况：30 岁，在贸易公司做行政，会用 Excel 做表，没有编程经验，打算业余时间学，每天 1–2 小时，预算几千块以内。下面的建议都基于这些条件，最后我会说明还有哪几个信息会影响具体安排。

## 一、先对齐现实，再谈路线

这个方向可行，但“报个班、学几个月、然后投简历”这条路走通的概率并不大。在决定怎么学之前，有几件事你最好先知道：

1. **初级数据岗竞争很激烈。** 招聘方对初级岗位的普遍硬门槛是 SQL + Excel，很多公司还会筛学历和专业（本科及以上、统计/数学/计算机相关优先）。有转行者分享过自己投了两百份简历只换来四五个面试的经历（这是单个发帖者的个人经历，不代表平均水平，但方向上说明：零经验直接投“数据分析师”头衔的岗位，简历通过率很低）。

2. **AI 正在改变这个岗位的入门层。** 2026 年以来行业讨论的大致共识是：纯取数、做报表这类执行型工作正在被 AI 工具自动化，初级岗位需求在收缩；留下来更有价值的，是“懂业务 + 会用 AI 工具 + 能把数据变成结论和行动”的人。这对你是双刃剑：坏消息是纯工具型岗位更难进了；好消息是你不需要把编程练到很深才起步，重心可以放在 SQL 和业务理解上，AI 工具反而能帮你补编程短板。

3. **你的优势恰恰是业务和 Excel。** 市面上缺的往往不是“会跑 Python 的人”，而是“懂业务、能耐心把数据弄干净、能说清数据说明了什么”的人。你做了多年行政，熟悉公司怎么运转；贸易公司里到处是订单、库存、物流、客户数据。对你来说，转行最稳的路径通常不是“换个行业从零开始”，而是“在熟悉的业务里换位置”。

## 二、学习路线：分四个阶段

按每天 1–2 小时（每周约 7–14 小时）估算。下面各阶段的时长是学习类资料的常见估计量级，个体差异很大，仅供安排节奏参考，不是承诺。

**阶段一：Excel 进阶（约 4–6 周）**

- 你已经会用 Excel 做表，这个阶段补的是“分析用”的功能：数据透视表、VLOOKUP/XLOOKUP、SUMIFS/COUNTIFS、常用文本和日期函数、数据清洗、基础图表和报表排版。
- 产出物：拿一份你手头真实的数据，做一份能拿给别人看的分析报表。
- 资源：B 站上的免费数据分析入门课程（比如戴师兄的免费课，覆盖 Excel、SQL、可视化，零基础友好）。

**阶段二：SQL（约 2–3 个月，整条路线里最重要的一段）**

- SQL 是这行的硬门槛，几乎每个数据岗位的招聘要求里都有。目标是“能独立取数”：SELECT、JOIN、GROUP BY、子查询，进阶再学窗口函数。
- 学法：先跟一遍系统教程（DataWhale 的开源课程 wonderful-sql，GitHub 上免费、有配套练习），然后到牛客网 SQL 题库刷题（免费，从入门题到大厂面试真题都有）。每天稳定刷 3–5 题就很好。
- 检验标准：拿到一个业务问题，能自己写出查询、从数据库里把数取出来、算对、并核对过。

**阶段三：一个 BI 可视化工具 + 统计基础（约 6–8 周，可与阶段二后半段并行）**

- BI 工具学一个就够：国内公司用帆软（FineBI/FineReport）较多，外企和出海方向常见 Power BI 或 Tableau。不确定就去招聘网站上搜你所在城市的数据岗，看哪个工具出现得多就学哪个。
- 统计不用学深：均值中位数、分布、相关性、假设检验的直觉，以及常见统计陷阱（幸存者偏差、相关不等于因果）就够了。
- 产出物：用公开数据集（Kaggle、和鲸社区等）做一个完整的可视化看板。

**阶段四：作品集 + 求职准备（从第 3–4 个月起持续进行）**

- 做 2–3 个完整的小项目，每个项目讲一个完整的故事：业务问题 → 数据处理 → 分析 → 结论和建议。数据可以用 Kaggle 公开数据集；更好的选择是用你工作中接触得到的真实场景（脱敏后），比如订单交付周期分析、客户复购分析、销售区域对比——这类项目招聘方一眼能看出你懂业务。
- 简历上写“分析出了什么结论、带来了什么改变”，而不是“熟悉 SQL、Excel”。

**Python 要不要学？** 入门阶段不是必需。Excel + SQL + 一个 BI 工具已经覆盖大量初级岗位的日常工作；Python（Pandas）等你需要处理更复杂的数据、或想拓宽岗位面时再补。不要一上来就学编程——那是无基础者最容易卡住劝退的弯路，而且它不是入行的第一道门。

## 三、几千块预算怎么花

入门阶段几乎不用花钱，免费资源完全够用：

- **免费主力**：B 站课程、DataWhale 开源课程、牛客网 SQL 题库、中国大学 MOOC 上的高校统计学与数据分析课、Kaggle/SQLZoo 等练习平台。
- **值得花的小钱（几百元内）**：一两本口碑好的入门书（SQL 入门、统计学入门各一本），纯当加速器。
- **暂时不建议花的钱**：
  - **入门培训班（几千到上万元）**：入门内容免费资源已覆盖；培训班的核心卖点是督促和就业承诺，而“包就业”类承诺在这行口碑很差，是转行劝退文章里被反复提醒的坑。
  - **证书**：CDA 等数据分析师证书的正面宣传大多来自证书官方和推广渠道（我在检索时特意核对了这一点），招聘要求里极少把证书列为硬门槛。等你到了求职阶段、发现目标岗位确实偏好时再考虑不迟，考试费用以官网当时报价为准。
- **留一半预算到找工作阶段**：那时花在简历修改、模拟面试或一次高质量的实战项目辅导上，性价比远高于现在报班。

## 四、比学习路线更关键的一步：从哪里进入这个行当

直接投“数据分析师”岗位，是你所有入口里难度最高的一个。结合你的条件，更现实的切入顺序是：

1. **先在现在的公司里制造机会（成本最低，现在就能开始）。** 贸易公司一定有大量数据活：销售报表、库存统计、订单跟踪、客户数据整理。主动把这些活揽过来，用你阶段一、二学的透视表和 SQL 把它做得比原来好，让领导和业务部门看到“这个人做数据比做行政更有价值”。内部转岗（数据专员、运营、跟单、带分析职责的助理岗）不需要你先去和市场上已有几年经验的人拼简历。这是你手里现成、且别人没有的资源，别浪费。
2. **相邻岗位作为跳板。** 数据专员、BI 报表、数据运营、经营分析助理这类岗位，工作内容和数据分析高度重叠，招聘门槛明显低于“分析师”头衔。先进门再内部流动，是过来人最常见的建议之一。
3. **把贸易行业背景变成差异化优势。** “懂外贸/供应链流程 + 会数据分析”的人，比“只会数据分析”的人好找工作得多。求职时优先投贸易、跨境电商、供应链、物流方向的数据岗，你的行业经验在那些地方是加分项而不是清零项。

## 五、给自己设的检查点

学技能本身低成本、可逆，真正的成本是时间，所以用阶段性观察来决定继续还是调整：

- **第 1 个月末**：学完 Excel 进阶和 SQL 入门。问自己：刷题和整理数据时，是“有点费劲但有意思”，还是“纯煎熬”？如果是后者且持续如此，说明这类工作的日常可能不适合你，值得重新考虑目标（比如转向“业务岗 + 数据技能”，而不是纯数据岗）。
- **第 3 个月末**：SQL 能独立完成中等难度的取数，做出第一个完整小项目。达标就按计划进阶段三。
- **第 6 个月末**：作品集有 2–3 个项目，开始投相邻岗位和内部机会。如果投出三五十份简历几乎没有任何面试回应，不要加大投入死磕“分析师”头衔——改投数据专员/BI/运营类岗位，或全力推动内部转岗；先进这一行，经验攒起来再换位置。
- **改判条件**：如果学了几个月后发现自己真正喜欢的是“用数据帮业务做决定”而不是“和数字打交道”，商业分析、运营方向可能比纯数据分析更适合你，学的东西也基本不浪费。

## 六、有几个信息会改变这条路线

以下是我目前不知道、但会影响具体建议的信息。你补充后，路线可以再校准：

- **你的学历和专业**：如果非本科，直接投外部初级分析岗会更难，上面“内部转岗 + 相邻岗位”路线的优先级要再提高；如果本科且专业偏数理，外部求职窗口更大，节奏可以更激进。
- **你在什么城市**：一二线城市数据岗密度高，小公司和内部转岗的机会都更多；小城市则更要依赖现公司的内部机会和相邻岗位。
- **你能接受多长的过渡期**：如果希望 6 个月内必须换工作，风险明显升高，“先内部转”几乎必然是更稳的路；如果能接受 1–2 年从容过渡，上面这条路线可以完整走完。
- **你为什么选数据分析**：如果是出于收入或摆脱行政的重复劳动，这条路线成立；如果只是听说“数据分析师高薪”，建议先按阶段一学一个月，确认自己不排斥再决定全部投入。
