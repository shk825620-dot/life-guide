# life-guide 通用技能重构需求计划（6.0.0 目标）

日期：2026-10-30
基线：5.1.14 候选版
用途：先统一需求、责任位和验收，再修改运行 Skill。本文不是能力宣传，也不把未验证项目写成已完成。

## 一、重构目标

让 Skill 在需要个人条件、当前证据、方案比较或现实行动的任务中，稳定完成：

1. 识别问题类型和宿主能力边界。
2. 找到用户原先没看到的相关路线，并说明搜索覆盖范围。
3. 对会改变行动的事实逐项核验，向用户显示来源、日期、适用范围和状态。
4. 在信息不足时先交付判断地图、风险边界和最低成本动作。
5. 在快速决断与重大决策两档中控制投入、停止继续调查，并保留改判条件。
6. 用户补充条件、现实结果或新证据后，明确保留、修改或推翻旧判断。

## 二、不能承诺的内容

不得写入运行规则或 README 能力保证：覆盖所有问题、穷尽所有选项、保证最优解、自动判断真假、保证工具无病毒/不封号、自动跳过验证码、保证 30 分钟得出正确答案、保证 2,000 Stars。

## 三、运行架构

### P0：唯一最小答复合同

新增 `references/output-contract.md`，作为用户可见答复的唯一最小字段定义：

- 当前判断或暂缓理由；
- 关键依据及状态（来源/链接、查询日期、适用范围，或明确“未核实”）；
- 最大未知与它会改变哪条路线；
- 方案取舍（机会成本、相对耗时、稳健性，低影响题可省略）；
- 最低成本下一步；
- 停止、改判或继续调查条件。

低影响事实题不强制完整合同；高影响题不得省略来源状态、最大未知、下一步和停止/改判条件。

### P0：宿主能力预检

新增 `references/capability-check.md`，在需要外部事实或工具前按“可用 / 不可用 / 未验证”记录：联网检索、官方页面打开、文件读取、计算、子 Agent、可靠计时、登录/外部写入。

能力不可用时必须降级：给检索计划、条件化判断或用户可执行的核实动作；不得把“应该查”写成“已经查”。

### P1：候选覆盖证明

扩展 `option-expansion.md`：按当前问题适用的维度扫描直接替代、相邻参与位置、上游/下游、交付方式、资源变现和低成本实验；输出已查类别、暂不展开类别及原因。

不能承诺穷尽；每个保留候选要有进入条件、验证动作和失败信号。

### P1：现实反馈闭环

扩展 `persistent-mode.md` 与 `decision-log.md`：高影响结论设置回访点，记录实际结果、偏差、未预料阻碍和是否改变路线。用户没有回访时，不把行动结果写成已验证事实。

### P1：停止与继续条件

扩展 `progressive-delivery.md`：每个检查点写当前阶段、已用资料/工具、最大未知、继续调查的预期收益、停止或转档条件。时长仍是投入量级，不伪造墙上时间。

### P2：来源压缩

保持 `search-playbook.md` 为证据方法唯一归属；在 `output-contract.md` 规定低复杂度短句、高影响四列或等价短句，避免完整底稿拖慢回答，也不能隐藏证据边界。

### P2：用户价值反馈

结论后可询问三项：发现的新选项、最有用的证据、仍缺失的内容。反馈作为后续改进输入，不自动当事实。

## 四、适配边界

核心 Skill 只写通用行为；宿主适配分别记录发现/触发、参考文件读取、搜索/浏览器、子 Agent、登录授权、计时和失败降级。X、微博、小红书按平台能力单独验证；没有工具时提供不依赖平台的替代路径。

插件安装须用户明确批准，展示来源、版本、维护状态、权限、数据流、许可证、回退和未验证项；不自动代替密码、验证码，不绕过限流和风控。

## 五、验收计划

1. 结构层：入口路由、单一责任位、版本、无私有路径、CI 覆盖。
2. 封闭材料层：候选覆盖、来源状态、停止条件、反馈更新，每类至少 3 个领域、每例 3 次。
3. 真实来源层：当前版本重复运行；包含官方来源可打开、来源冲突和原文打不开三类。
4. 宿主层：WorkBuddy 干净安装/触发/参考文件读取/工具降级；再选一个标准兼容宿主。
5. 用户层：真实用户反馈是否发现新路线、是否改变行动、是否浪费投入。

每层单独判定；任何一层未完成都不得用其他层的 PASS 代替。

## 六、实施顺序

1. 先加 P0 输出合同和宿主能力预检。
2. 再补候选覆盖证明、停止条件和反馈闭环。
3. 运行封闭材料回归与当前版本真实来源试跑。
4. 修复重复规则和冲突后，再做宿主适配与发布评估。

## 七、当前审查结论

5.1.14 的主链路可手动试用，但仍缺统一输出合同、能力预检、候选覆盖证明、现实反馈闭环和当前版本真实来源行为证据。这些是下一轮重构的根因级任务；不能靠继续堆示例或重复写宣传语解决。
