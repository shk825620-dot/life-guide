## 本轮改造范围

- 将 `SKILL.md` 改为 Agent Skills 标准顶层元数据，版本 `4.0.0` 放在 `metadata.version`。
- 将个人需求、个人知识库协议、私人智慧库、WorkBuddy 本机路径、一次性任务书和开发验收框架从运行包移出，并保留在本机忽略目录 `审查证据/内部项目资料-2026-10-18/`。
- 将主流程改为通用规则；书籍、本地笔记和知识库不再是运行条件。
- 将五个角色定义为按需任务卡：选项空间、成熟方案与复用、主张与时效、规则与例外、现实可行性。
- 重写快/深调查、工具访问、澄清和决策参考，去除个人机器、插件候选和单一地区默认值。
- 更新 GitHub 项目介绍、包边界、维护方法和 WorkBuddy 适配状态。
