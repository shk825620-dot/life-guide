# 打开可行的选择

## 何时读

用户需要找方向、成熟方案或其他路线，或现有候选可能只来自熟悉范围时读取。目标是发现与其目的有关、值得核查的不同路径，不能以候选数量代替质量。个人关键需求未明时先按 needs-clarification.md 提问并等待；用户明确要通用概览时，可说明路径类别，不冒充个人推荐。

## 1. 检查候选边界

先区分“要达成什么”和“目前想到怎么做”。用户说想增加收入，不等于已经决定开店；用户已明确只比较两份录用通知，则尊重该范围，不强行改为创业或读研。

确认现有候选来自哪里：用户已调查、熟人建议、热门榜单、搜索结果还是 AI 的初始联想。它们是起点，不是全部可能性。不要要求用户列出自己尚不知道的选项。

只向用户询问会影响范围的关键个人信息。调查对象、检索词、候选构造和适配分析由 AI 完成。

## 2. 按本题选维度，发现不同路径

下表是可选的观察方向，不是每题必填的表格，也不要求把所有组合都列出。

| 观察方向 | 可调查的问题 |
| --- | --- |
| 需求与客户 | 谁在什么场景有反复出现的问题？谁使用、谁付钱？是否把某种实现方式误当目标？ |
| 系统中的参与位置 | 除终端产品或门店，上游、下游、渠道、配套服务、维护、流通等是否有相关路径？ |
| 交付方式 | 自己做、现成工具、服务采购、合作、经销、租用、人工或自动化，哪些能满足同一目标？ |
| 进入与能力形成 | 自建资源之外，是否能先用小单、短期试用、合作分工、学习或借助既有设施验证？ |
| 时间与替代安排 | 能否分阶段、先试后扩大、保留原方案、延后或不做？用户已设定的期限继续生效。 |
| 规则与可用资源 | 是否有影响准入、资格、费用、地域或使用条件的规则及既有资源？需要查具体地区与现行依据。 |

选与当前问题有关的维度生成实质不同的路径，再核对组合能否同时成立。不把“想得到”当“市场存在”，不把理论组合数当现实可选数量。

### 把用户提到的关系和资源转成候选路线

当用户提到能接触行业、客户、货源、设备、场地、渠道、专业能力或合作方的关系与资源时，检查它**实际打开了系统里的哪个参与位置或交付方式**。不要只把它记成初始方案的优势。

例如，“表姐在服装批发市场、能帮忙拿货”除了可能降低自己卖衣服的进货门槛，也应检查代销、分销、撮合供货、小批量试卖等是否现实可行。路线要由资源能提供的具体权限、条件和责任推出，不能因为认识人就假定能拿到低价、稳定供货、客户或利润。

呈现时区分：**已知资源/关系**、**它开启的候选线索**、**仍待验证的需求或交易**。核查谁付钱、谁承担库存/售后/退换/履约责任、关系方是否同意以及实际成本。若该资源与目标无关，说明不影响候选范围；不要为凑选项强行关联。

候选线索可以来自行业流程、采购和服务目录、真实供需记录、现成产品及社区实践；涉及关键能力、费用或规则时回查对应一手材料，社区说法不能单独证明收益或普遍需求。

## 3. 用证据和条件检查路径

对值得继续的路线，说明：

- **具体在做什么**：服务谁、解决什么问题、怎样交付；商业场景另查谁付费及为何付费。
- **依据是什么**：已观察到的做法与来源，或尚待核查的设想；发现案例不代表有本地需求。
- **当前适配性**：投入、时间、能力、客户来源、地区与规则、获客和履约责任；不要编造行情或回报率。
- **可达性**：现在可试；满足写明的条件后可试；或当前不适用并说明原因。法律、权限、不可承受的损失及用户明确禁止项是现实边界，不能仅因不是物理定律就绕开。
- **最低成本检验**：查哪份材料、问哪类人、试交付什么，以及什么结果支持继续、调整或停止。AI 可做的调查直接完成，个人经历或实际需求反馈才交接用户。

分清硬约束、用户可选择改变的条件与未经验证的假设。能力不足可以提出补齐路径，但不能假定用户愿意额外投入；当前预算不足不能被“以后会赚钱”抹掉。

## 4. 呈现与收敛

先让用户看懂路径之间的差别，再展开最相关的候选。可用“路径｜为何相关｜门槛与未知｜怎么验证”表格，给主推荐和何时备选更好，不输出一长串名词让用户独自筛选。用户要求更完整时展开相关类别与遗漏，不任意隐去有意义的路线。

停止前检查：是否只在同一类熟悉方案里比较；是否有足以改变选择的替代形态尚未查；关键前提是否真实；已有调查能否支持下一步。报告未覆盖部分，不用“没有新搜索结果”证明已经穷尽。

## 5. 示例：小生意的参与位置

这是观察维度示意，**不是已验证商机或创业推荐**。真实推荐必须结合用户条件、当地需求与现行规则调查。

| 位置 | 可进一步调查的不同做法 | 不能略过的区别 |
| --- | --- | --- |
| 面向消费者 | 门店、摊位、预约或合作销售 | 场地、时间、获客和履约不同 |
| 原料及耗材 | 原料、杯、吸管等的制造、经销、采购协作 | 制造、代理、撮合不是同样的投资与责任 |
| 设备 | 制造、销售、租赁、维修协作 | 拥有或制造制冰机，与对接现有服务商的能力要求不同 |
| 配套服务与流通 | 具体运营服务、配送、清洗维保、二手流通 | 先确认真实需求、资质、技能、收费和责任，不能只列名词 |

不能从“看到上游”推出上游一定更赚钱。也不能因为用户目前没工厂，就把所有供应相关路径一并删除；可调查现有服务合作，但必须说明尚缺条件和风险。

学习、职业、城市和技术选择同样先检查候选边界，再按其问题选观察维度；不能把所有问题都套成产业链分析。
