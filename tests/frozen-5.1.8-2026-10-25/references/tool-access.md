# 按需工具与账号访问

本文件用于当前任务确实需要额外访问能力时；不要求用户安装固定插件，也不假设某个宿主具备某种工具。

## 最小接入顺序

1. 盘点当前 Agent/宿主已提供的搜索、文件、浏览器、代码和连接器能力，先复用可用项。
2. 说明缺少什么能力、它会解决哪一步、有没有不安装工具的替代路线。
3. 若任务确有必要，再评估候选工具：官方来源与发布者、许可证、维护状态、平台/宿主兼容、费用、权限、数据处理方式、卸载回退和公开安全记录。
4. **安装前必须把候选名称、来源链接、版本、权限、费用、数据流向、账号影响、回退方式和未验证风险列给用户，由用户明确批准本次安装。** 未获批准时只给替代路径，不自行下载、安装、升级或启用。
5. 付费、账号授权、权限扩大、首次登录、扫码或验证码由用户明确操作；保留当前调查进度，之后继续。
6. 只授予完成本次任务所需的最低访问范围。读取授权不等于发帖、评论、点赞、购买或其他写入授权。

## 候选工具的可信度与账号安全

- 优先推荐官方商店、项目官方仓库、可核验维护者或宿主内置工具；核对许可证、最近维护、发布页、依赖、权限范围、公开漏洞/安全公告和卸载方式。
- “高评分、很多人推荐、Star 多”只是社会信号；**不能保证无病毒、无恶意代码、无数据收集或不会被平台限制**。无法独立验证安全性时，必须写“未能保证”，不使用“绝对安全/无毒”。
- 不为提高抓取量而自动刷新、并发轰炸、轮换账号、隐藏自动化特征或规避平台条款；控制频率，遵守目标平台的服务条款和官方接口限制。
- 登录只在用户明确授权且宿主提供合规登录流程时进行；用户自己完成密码、扫码、验证码和二次验证。不得索取、保存或公开密码、Cookie、Token 或浏览器登录态。
- 安装或登录可能导致限流、风控、账号封禁甚至用户账号被封号时，先提示风险并提供不登录的替代来源；遇到验证码、限流或警告立即停止该路径，不通过插件跳过或伪造验证。
- 安全状态只能分为“来源可核验/权限已审阅/已在本环境验证/仍未验证”；没有安全扫描或沙箱证据，不把推荐写成安全保证。

## 访问失败与限制

- 不自动绕过验证码、登录验证、平台风控或速率限制；不使用反复刷新或无限重试。
- 遇到验证码、限流、登录失效或禁止访问，停止该路径，按官方重试要求处理或改用其他可访问来源。
- 受限资料没有核实到就标明；不得声称“已经查过”。替代来源不足时缩小结论范围。
- 不保证某个工具兼容所有宿主，也不保证登录后不会被限制。

## 凭证与数据

密码、Cookie、Token、浏览器登录态文件和私人资料不得写入公开仓库、聊天截图或公开测试记录。子 Agent 只接收完成其任务所需的最少信息。运行需要向外发送数据时，先核对目标、数据范围与用户授权；授权不清时不发送。

## 状态描述

区分“已安装”“配置完成”“权限已授权”“访问成功”和“目标资料已核实”。完成前一项不代表后一项完成。只报告实际操作和结果；文档核查不能写成实测兼容。
