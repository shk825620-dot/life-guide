# 转行数据分析：给你的学习路线建议

先复述一下你的情况，确认我理解对了：30 岁，贸易公司行政，会用 Excel 做表，没有编程经验，每天能挤 1–2 小时业余时间，预算几千块以内。

你的条件其实比很多想转行的人好——Excel 是数据分析真正的第一门槛，你已经在门槛上了。但在给你排学习计划之前，我要先说一个很多人不会告诉你的现实，因为它直接决定路线怎么设计。

## 一、先说实话：直接投简历这条路，现在最难走

**初级数据分析岗这两年的竞争非常激烈。** 我检索到的多方信息一致指向：纯"取数、做表、出报表"型的初级岗位供过于求，正被 AI 工具和更年轻的竞争者（2026 年有上千万应届生进入职场）两头挤压；相对抢手的是"懂业务 + 会用 AI 工具 + 有行业纵深"的人。有从业者的经验帖也普遍提到，零经验转行往往要接受起点降低（先去小公司或数据专员岗）、并预留两三年沉淀期。

这意味着：**如果你学完 SQL 和 Python 就裸投"数据分析师"岗位，你要跟科班应届生和大量转行者在同一个池子里拼，30 岁零编程背景是劣势。**

但好消息是：你有两样应届生没有的东西——**贸易行业的业务理解**，和**一个现成的、每天都在产生数据的公司**。订单、库存、客户、供应商、回款、物流……贸易公司全是数据，而行政往往是离这些报表最近的人之一。所以我的主推荐不是"辞职报班转行"，而是：

> **以现公司为练习场和跳板：先学技能 → 用在当前工作上做出看得见的成绩 → 内部转岗或带着行业作品跳槽。** 这条路风险最低、几乎不花预算，而且"懂贸易业务的数据分析"比"什么行业都不懂的数据分析"好找工作得多。

如果你毕业后就是不想留在贸易行业，下面的学习路线同样适用，只是求职阶段的难度会高一些（后面第六节会细说）。

## 二、学什么、按什么顺序

综合我核对过的 2026 年学习路线资料，初级岗位的能力排序大致是：**业务理解 > SQL > Excel > 可视化 > 统计学 > Python**。注意 Python 排最后——很多新手一上来啃 Python，半年还在语法里打转，其实初级岗 80% 的日常是取数、清洗、做表、写结论。按下面的顺序走：

**阶段 0：试水（第 1–2 周，花费 0 元）**
先花两周免费试学，确认你不是"只想逃离行政"，而是真的能接受跟数据打交道（表结构、脏数据、反复核对）。逃离式转行是过来人提到最多的后悔原因。

**阶段 1：Excel 进阶（第 1–2 个月，基本 0 元）**
数据透视表（必须精通）、常用函数（VLOOKUP/XLOOKUP、IF、SUMIFS）、Power Query 清洗数据。你已经有基础，这一步是把你"会做表"升级成"会自动化地做表"。**学完立刻用在公司**：把你手头某个手工 Excel 报表改造成透视表 + 自动刷新的版本。这就是你的第一个作品。

**阶段 2：SQL（第 2–4 个月，基本 0 元）**
SQL 是招聘要求里出现频率最高的技能，也是所有路线共识中最重要的一项。目标：能独立写多表连接（JOIN）、分组聚合（GROUP BY）、子查询。免费资源完全够：B 站上有零基础入门课（比如 CDA 的约 29 小时免费教程），刷题用牛客网、SQLZOO 或 LeetCode 数据库题。每天 1 小时，三个月能到胜任水平。

**阶段 3：可视化工具 + 统计基础（第 4–6 个月，可选花几百到一千）**
- BI 工具选一个：国内企业用**帆软 FineBI** 的多，外企/大厂常用 **Power BI 或 Tableau**。看你目标公司类型选，选一个学精就行。
- 统计学补到能看懂：描述统计、相关与因果、假设检验、AB 测试的概念。不需要数学系深度，需要的是不被数字忽悠、也不拿数字忽悠人。

**阶段 4：Python（第 6 个月以后，按需）**
pandas 做数据处理，学到"能替代手工清洗"即可。这一步可以等你前面都扎实了、或者发现工作确实需要再学。同时，不管到哪个阶段，**把 AI 工具用进分析流程**（让 AI 辅助写 SQL、检查思路、生成报告初稿）已经是明显的差异化能力，而且你是零编程背景，AI 反而能大幅降低你的学习坡度。

**贯穿全程：做 1–2 个完整作品。** 最好的素材就是你公司的业务数据（脱敏处理）或公开数据集：用 SQL 取数 → Excel/BI 清洗可视化 → 写一页"发现了什么问题、建议怎么办"。面试时，一个讲清业务洞察的作品，胜过简历上罗列十个工具名。

## 三、时间预期（按每天 1–2 小时算）

每天 1–2 小时约合每周 7–14 小时，这个量够，但要把预期定准：

- **4–6 个月**：达到"能承担公司里数据类工作"的水平（内部转岗的现实门槛）；
- **9–12 个月以上**：积累出像样的作品集、可以开始对外看机会；
- 对外求职要有**起点降低**的心理准备：第一份数据岗可能 title 更初级、薪资不涨甚至略降，这是转行经验帖里最普遍的共识。把它当作两三年爬坡期的起点，而不是失败。

## 四、几千块预算怎么花（以及坚决不花在哪）

**够用，而且大部分应该省着花：**

- 0 元：B 站免费课、官方文档、免费刷题站——入门内容免费资源非常充足；
- 100–300 元：一两本经典入门书（如 SQL 入门类）；
- 1000–2000 元（可选）：如果自学到某个点卡住了，再考虑一门试听过的线上进阶课。**先试听再付钱，别反着来**；
- 留几百块机动。

**坚决不碰的：**

1. **线下"就业班"**：检索到的报价普遍在 2 万–2.5 万元，远超你预算，且对"懂业务+内部转岗"这条路线毫无必要（费用为检索结果中的常见报价，属二手信息，量级供参考，未逐条核实原文）；
2. **任何"包就业""保证月薪过万"的承诺**：北京市市场监管局 2025 年 9 月刚查处过"免费课程引流—高价课—退费难"的典型案例；中国消费者协会 2026 年一季度投诉分析也点名了"包过""不过退款"类承诺问题。正规机构只会说"就业辅导/推荐就业"，不会承诺"包就业"；
3. **任何形式的"先就业后付款""培训贷""零元入学分期"**：这是教培投诉的重灾区，退费极难。

报名前花十分钟：在黑猫投诉等平台搜一下机构名称，看历史投诉记录。

## 五、有三个问题会改变我的建议（你可以之后补充）

1. **你在哪个城市（或想去哪个城市）？** 一线和二三线的初级数据岗数量、薪资差异很大（检索到的说法：二三线初中级数据分析师常见 8–15K，一线略高但竞争更集中）。城市决定了对外求职的难度，也决定该不该把"现公司转岗"的权重放更高。
2. **你想多快完成转行？** 如果希望 6 个月内就换工作，那"边工作边学"的节奏会很赶，要么延长时间投入，要么调整预期；如果不急，两年爬坡期完全可行，路线可以走得扎实得多。
3. **你想转行的真实动机是什么？** 是对数据工作本身有兴趣，还是主要想逃离行政？前者这条路走得通；后者的话，"行政 + 数据技能"的复合定位（懂数据的行政/运营，在原公司往往更值钱）可能是性价比更高的变体，不必先给自己贴上"必须转行"的死目标。

## 六、什么情况下应该改判

- **如果 1–2 个月后你发现自己排斥 SQL/数据处理本身**：停止投入，转向"Excel 精通型"的行政/运营定位，前期投入不浪费；
- **如果 6 个月后公司内确实没有任何数据类工作可沾、当地市场也找不到贸易行业的数据岗**：把目标调整为"数据运营/供应链分析/CRM 数据管理"这类门槛更低的相邻岗位，或扩大求职城市范围；
- **如果出现"不报 2 万的班就学不会"的念头**：先回来对照第四节——这条路线的所有知识，免费资源都覆盖了，几千块预算里没有一分钱必须给培训机构。

## 七、本周就能做的三件事

1. **今天就做**：挑一个你手头最繁琐的手工 Excel 报表，试着用数据透视表重做一遍（B 站搜"数据透视表 入门"，现学现用）。这是零成本验证：既测学习手感，又直接产出作品；
2. **本周内**：在 B 站找一个播放量高的免费 SQL 入门课，收藏进列表，下周一正式开始每天 1 小时；
3. **两周内**：约 2–3 个真实的数据从业者聊聊（脉脉、LinkedIn，或朋友的朋友），只问一个问题："你日常一天的工作具体在干什么？"——用真实工作内容校准你对这个职业的想象，比任何课程介绍都可靠。两周后自检：SQL 学习是否坚持得下来、是否有手感。**坚持不下来或很排斥，就是最早、成本最低的止损信号。**
