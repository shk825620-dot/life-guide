先确认一下我理解的情况：你 30 岁，在贸易公司做行政，用过 Excel 做表格，没有编程经验；打算业余时间学，每天能挤出 1–2 小时，预算几千块以内，目标是转行做数据分析。（我默认你说的是"业务数据分析"——用 SQL、Excel、BI 工具做业务分析，而不是机器学习算法岗；如果你指的是后者，路线完全不同，请告诉我。）

先给你吃个定心丸：**钱不是这个计划里的瓶颈。** 数据分析是少数几乎可以零成本自学入行的方向，免费的学习资源、练习平台和工具都很成熟，你几千块的预算大概率花不完。真正的瓶颈是两点：一是每天 1–2 小时能否坚持半年以上，二是方向别选偏。所以下面先问几个会改变路线的问题，再把已经可以确定的部分和第一周就能动手的事给你。

## 一、四个会改变路线的问题

**1. 你的学历是本科吗？（影响最大）**

国内数据分析岗位普遍把本科当门槛。我检索到一篇对上海数据分析岗位的统计文章，称本科学历要求占约 83%（[知乎文章](https://zhuanlan.zhihu.com/p/543851294)，检索日期 2026-10-24；这是二手数据，仅作参考，别当精确数字）。最可靠的核实方法见下面第二部分第一周的动作。

- 如果你是本科：常规的外部求职路线成立，按下面的计划走。
- 如果是大专或更低：直接投简历会难很多，但计划不作废——主路线改成"行业内部路线"（见第四部分）：先在贸易行业内转到带数据职责的岗位，或瞄准学历要求更宽松的数据专员、报表岗，边做边补。这类岗位对实际经验和作品的权重通常高于学历。

**2. 你想留在贸易/外贸行业，还是不限行业？**

初级数据分析岗竞争很激烈，转行者很多，只凭"会 SQL 和 Excel"很难突出。你手里有一张别人没有的牌：贸易行业经验。如果目标定成"贸易/外贸/跨境电商行业的数据岗"，行业理解就是你的差异化优势；如果完全不限定行业，就得靠作品集硬拼，准备期明显更长。

**3. 你期望多久转过去？**

按每天 1–2 小时投入，比较现实的估计是 8–12 个月达到能求职的水平（这是经验估计，我没有可靠的成功率数据可以引用，建议用第一周的岗位调研来校准）。如果期望是 3 个月内，要么加大投入，要么把目标先调整为数据专员、报表类岗位过渡。

**4. 你在哪个城市？** 这决定岗位供给量，也影响要不要把远程岗位纳入考虑。

## 二、暂定学习路线

以下骨架在上述问题的各条分支下都成立，可以先动起来；等你补充信息后，我再细化成按周排的计划。

**第 1–2 周：岗位调研 + Excel 补强**

- 花几个小时做一件事：打开你所在城市常用的招聘 App，搜"数据分析师""商业分析师""数据专员"，把前 20 条岗位的学历要求和技能关键词记下来。高频词大致会是 SQL、Excel、可视化（BI 工具）、业务分析，部分还要求 Python。这份清单就是你真实的学习大纲，比任何通用路线都准，也顺手完成了问题 1 的核实。
- Excel 你有底子，重点补四样：数据透视表、VLOOKUP/XLOOKUP、SUMIFS/COUNTIFS、常用图表。入门书可以用《谁说菜鸟不会数据分析（入门篇）》（电子工业出版社，基于 Excel 展开，已出至第 4 版；[百度百科词条](https://baike.baidu.com/item/%E8%B0%81%E8%AF%B4%E8%8F%9C%E9%B8%9F%E4%B8%8D%E4%BC%9A%E6%95%B0%E6%8D%AE%E5%88%86%E6%9E%90/5360660)、[出版社页面](https://phei.com.cn/module/goods/wssd_content.jsp?bookid=54122)，检索日期 2026-10-24），几十块钱；不想花钱先在 B 站找免费教程也可以。

**第 2–8 周：SQL（最优先的硬技能）**

招聘要求里出现频率最高的就是 SQL，几乎每个数据岗都绕不开。免费路径两步：

1. [SQLBolt](https://sqlbolt.com)：免费网页交互课程，约 20 课，从基本查询到 JOIN、聚合、子查询都有，不用注册、不用付费（官网核实，检索日期 2026-10-24）。
2. [牛客网 SQL 题库](https://www.nowcoder.com/ta/sql)：免费在线刷题、即时判题，有讨论区和题解，把练习量刷上去（检索日期 2026-10-24）。

每天 1 小时，六周左右能到应付多数面试题的水平。

**第 8–16 周：统计与分析方法 + 一个 BI 工具**

- 统计不用啃教材：描述统计、分组对比、漏斗/留存/RFM 这类业务分析方法够入门用，B 站免费课很多。
- BI 工具选一个上手并做出成品：
  - Power BI Desktop：微软官方定价页注明可免费下载使用（个人学习免费，共享协作等企业功能才收费；[微软官方定价页](https://www.microsoft.com/en-us/power-platform/products/power-bi/pricing)，检索日期 2026-10-24）。
  - Tableau Public：官网注明"探索、创建、分享全程免费"，适合搭作品集（[官网](https://www.tableau.com/zh-cn/community/public)，检索日期 2026-10-24）。
  - 国内公司常用的帆软 FineBI 官方提供免费试用，但我在其官网没有查到长期免费的个人版（检索日期 2026-10-24），所以入门先学上面两个即可；工具之间迁移不难，之后按目标公司的要求再补。

**第 16–24 周：做出 2–3 个作品**

用公开数据集（Kaggle、阿里云天池、政府公开数据）走一遍完整流程：提出问题→取数→清洗→分析→可视化→结论建议。强烈建议其中至少一个和贸易业务相关（订单分析、客户复购、库存周转、汇率波动对利润的影响等）——这是把你的行业经验变成面试筹码的机会，也是和科班候选人拉开差距的地方。

**之后**：回头对照第 1–2 周记下的岗位关键词，决定要不要补 Python（很多初级岗写的是"会 Python 优先"，不是硬性要求），然后进入简历和面试准备。别一上来就买 Python 大课。

## 三、预算怎么安排

- 全程免费资源（SQLBolt、牛客、B 站、Power BI/Tableau 免费版）加一两本书，几百元就能走完入门，你的"几千块以内"绰绰有余。
- 剩下的钱先不花。市面上几千到上万的"数据分析训练营"，教学内容与上述免费资源高度重叠；对"包就业、保薪"这类承诺，签约前务必核实合同条款和退费规则。以你的时间条件，自学路线完全走得通。
- 证书类（如 CDA 数据分析师认证）在社区讨论里也只是"加分项"而非门槛（[相关讨论](https://juejin.cn/post/7685907832281071662)，检索日期 2026-10-24；社区说法，仅作参考），预算有限时优先投作品集，不投证书。
- 真想花钱，优先级：书 → 求职阶段的简历打磨/模拟面试 → 都满足后再考虑课程。

## 四、一条更稳的并行路线（建议从本周开始）

不要等"学完再转"。从现在起在现公司主动沾数据：行政工作里的报表、对账、订单/库存统计，主动接过来做；业务部门有数据需求时主动帮忙。这一步零成本、零风险，好处有三个：

- 简历能从"行政"变成"行政 + 数据支持"，比空窗期硬转好解释得多；
- 30 岁转行，"行业内转岗"的成功率通常比"跨行零经验投简历"高；
- 无论最终是否跳槽，这些都是第一批真实案例。

另外提醒一个现实变化：这两年入门级"取数、做表"类工作正在被 AI 工具压缩，纯工具技能的竞争力在下降，业务理解和把分析结论落地的能力在升值。这对有行业背景的人反而是利好，也是我把"行业 + 数据"作为主策略的原因之一（这是我的判断，供你参考）。

## 五、什么情况要调整计划

- SQL 学完入门（约 1–2 个月）后如果发现自己完全提不起兴趣——这个岗位日常大量时间在取数、洗数据、对口径，和想象中可能不一样——及时调整方向，比如转向数据运营，或留在行政序列把 Excel/BI 做成特长。
- 岗位调研发现你所在城市数据岗极少、或学历门槛全部过不去——主路线切换到第四部分的行业内部路线。
- 6 个月时作品集仍没影、或对照招聘关键词发现学的东西对不上——停下来重排计划，别闷头继续学。
