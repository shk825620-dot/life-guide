# 30 岁行政转数据分析：一份可执行的学习路线

## 先说结论

你的条件（会用 Excel、每天 1–2 小时、预算几千块）转数据分析是完全可行的，但要把预期校准好：

- **周期**：业余学习 10–12 个月，达到初级岗位的求职水平。别信"三个月转行"的说法，那是脱产全职学习的节奏。
- **路线**：Excel 进阶 → SQL + 统计 → BI 工具 → Python + 项目集，一条主线走完。
- **策略**：不裸辞、不报上万的培训班，边工作边攒作品集，优先瞄准"贸易/供应链/电商"方向的数据岗——你有贸易公司背景，这是你相比纯小白最大的优势。
- **花费**：几千块绰绰有余。书约 200 元，可选网课 500–1500 元，其余工具全部免费。

---

## 阶段一（第 1–2 个月）：Excel 进阶 + 数据思维

你有 Excel 底子，这一步是把"做表格"升级为"用表格分析"。

**学什么：**
- 数据透视表（重中之重：分组汇总、切片器、多表联动）
- 核心函数：VLOOKUP / XLOOKUP、SUMIFS / COUNTIFS、IF 嵌套、TEXT 日期处理
- 数据清洗：去重、分列、格式规范、缺失值处理
- 图表规范：什么数据用什么图、坐标轴和配色的基本规矩

**资源：**
- B 站"王佩丰 Excel 24 讲"（免费，公认最好的入门课）
- 书：《谁说菜鸟不会数据分析》（Excel + 分析思维一起入门，很适合你）

**达标检验：** 把你现在手头的行政表格重做一遍，用透视表和函数替代所有手工统计，并写出三条你从数据里看到的结论。做到这一点，阶段一就算完成。

---

## 阶段二（第 3–5 个月）：SQL + 统计基础

SQL 是数据分析师的硬通货，招聘 JD 里出现率最高的一笔，务必学扎实。

**学什么（SQL）：**
- 增删改查基本语法 → WHERE / GROUP BY / HAVING → 多表 JOIN → 子查询 → 窗口函数
- 安装免费的 MySQL 自己建库练手；前期也可以直接在牛客网网页端刷题，零安装门槛

**资源：**
- 书：《SQL必知必会》（薄、快、够用）
- 练习：牛客网 SQL 题库刷 100 题以上（从简单到中等）

**学什么（统计）：**
- 描述统计（均值、中位数、方差、分位数）、同比环比
- 概率基础、假设检验的思想、相关与回归的直觉理解

**资源：** 书《深入浅出统计学》，不用啃数学证明，建立"用数字说话"的直觉即可。

**达标检验：** 不看答案，独立写出三表 JOIN 加分组聚合的查询；能向别人解释"这个月销售额下降，怎么从数据上找原因"的思路。

---

## 阶段三（第 6–7 个月）：BI 工具 + 第一个完整项目

**学什么：**
- 选一个 BI 工具学深：推荐 **Power BI Desktop**（免费、外企和贸易公司常用）；如果想贴合国内公司，可以加学 **FineBI**（帆软，国内企业渗透率高）
- 数据建模的基本概念：维度、度量、关系

**做第一个完整项目（关键一步）：**
结合你的贸易公司业务，用脱敏数据或自造数据做一份"销售/订单/库存"仪表盘：
- 数据从哪来 → 怎么清洗 → 关键指标是什么（订单量、客单价、周转率、同比环比）→ 图表怎么组织 → 得出什么结论和建议

**达标检验：** 一份能拿去面试讲的 Dashboard，外加一页分析结论。面试官问细节时你每个数字都答得上来。

---

## 阶段四（第 8–10 个月）：Python（pandas 为主）+ 项目集

Python 是加分项，别一上来就学它，前面三个阶段的产出更快、回报更高。

**学什么：**
- Anaconda + Jupyter 环境
- pandas：读写文件、筛选、分组聚合、合并、缺失值处理
- matplotlib / seaborn：常用图表即可
- 不用急着学爬虫和机器学习，初级分析岗基本用不到

**资源：** B 站免费 pandas 教程（跟着敲代码），书《利用 Python 进行数据分析》当工具书查。

**攒项目集（2–3 个）：**
- 数据来源：天池、Kaggle 的公开数据集，最好选电商、贸易、物流相关
- 每个项目按"业务问题 → 数据清洗 → 分析过程 → 图表 → 结论建议"产出一份报告（Markdown 或 PDF）
- 其中一个项目用你自己公司的业务场景来做，面试时讲业务逻辑最自然

---

## 第 11–12 个月：求职落地

- **简历**：突出"业务理解 + 工具 + 项目"，把行政工作里和数据沾边的经历都重新包装（报表统计、对账、流程数据化都算）
- **目标岗位**（按现实程度排序）：贸易/供应链/电商方向的数据分析 → 数据运营 → 商业分析
- **备选路径**：如果外部机会不顺，先争取在现公司内部转岗（行政转业务支持/运营岗，逐步靠近数据），或在现岗位主动承担更多数据工作，攒出"半个分析岗"的经验再跳，成功率更高
- **面试准备**：SQL 现场手写题 + 项目细节追问 + 业务 case（"销售额降了怎么分析"这类框架题），提前用牛客面经练

---

## 预算怎么花（几千块足够）

| 项目 | 花费 | 说明 |
|---|---|---|
| 书 4 本（菜鸟数据分析、SQL必知必会、深入浅出统计学、利用Python进行数据分析） | 约 200 元 | 核心投入 |
| 网课（可选） | 500–1500 元 | 只在自学卡壳时买一两门系统课，别囤课 |
| MySQL / Power BI / Anaconda / B 站教程 | 0 元 | 全部免费 |
| 证书（可选） | 500–1000 元 | BDA、CPDA 之类是锦上添花，不考也不影响求职 |

**明确不建议**：上万元的"包就业"培训班和培训贷。你的预算和自驱力足够走自学路线，培训班的价值大部分是逼你学习，而这个钱换成作品集投入产出比更高。

---

## 每周时间安排示例

- 工作日每天 1–1.5 小时：学新知识（看课 + 跟练）
- 周末各 2 小时：做题、做项目、复盘
- 每周合计约 10 小时，一年约 500 小时，完成上面整条路线是够的

---

## 五个避坑提醒

1. **别从 Python 开始。** 从 Excel 和 SQL 入手见效快、有产出，信心和正反馈比什么都重要。
2. **学工具必须带着业务问题。** 常问自己"这个数据能回答什么业务问题"，分析思维比工具更稀缺，也更有区分度。
3. **别囤课、别收集资料。** 一门学完再买下一门，收藏夹吃灰是转行失败的第一大原因。
4. **别裸辞。** 30 岁有收入压力，边工作边准备，作品集攒够、拿到 offer 再动。
5. **每个阶段有达标检验，别糊弄自己。** 看完课不等于会，能独立复现、能讲清楚才算数。

按这条路线走，一年后你手里会有：扎实的 Excel + SQL、一个 BI 仪表盘、2–3 个带业务结论的分析项目、以及贸易行业的领域理解——这正是一个"业务型数据分析师"岗位最需要的东西。
