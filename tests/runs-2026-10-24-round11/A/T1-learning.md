# 转行数据分析：为你定制的学习路线

## 先说结论

以你每天 1–2 小时、预算几千块的情况，比较现实的目标是：**用 10–12 个月，走"Excel 进阶 → SQL → 统计与业务思维 → Python → BI 可视化 → 作品集求职"这条路线**。这条路线几乎可以全程用免费资源加几本书完成，总花费控制在 1000–2000 元完全够用，不需要报上万元的培训班。

还有一点要先说在前面：**最平滑的转行路径，很可能不是直接跳槽，而是先在现在这家贸易公司里"转岗"**。行政岗位接触订单、库存、对账、报表，这些都是数据。你可以先主动把部门里重复性的表格工作做成自动化报表，攒出真实项目和"我用数据帮业务省了时间"的故事，一年后再带着这些去跳槽，会比零经验硬投容易得多。

## 你手里的牌其实不差

- **会用 Excel**：说明你对表格、数据不怵，这是很好的起点，数据分析的日常工作中 Excel 仍然占很大比重。
- **贸易公司业务背景**：懂订单流程、供应链、进销存的分析师在相关行业是加分项。很多科班出身的人反而缺业务感，这是你的差异化优势。
- **30 岁**：不算晚。数据分析不是青春饭行业，懂业务的中级分析师很吃香。但要接受一个现实：第一份数据类工作的薪资可能和现在持平甚至略低，真正上台阶是工作两三年之后。

## 学习路线：五个阶段

### 阶段一：Excel 进阶（第 1–2 个月）

目标：从"会用表格"升级到"会用 Excel 做分析"。

学这些：
- **数据透视表**（重点中的重点，90% 的日常分析靠它）
- 常用函数：VLOOKUP / XLOOKUP、SUMIFS、COUNTIFS、IF 嵌套、文本和日期函数
- **Power Query**（清洗数据的神器，也是过渡到自动化思维的一步）
- 基础图表选择：什么数据该用什么图

资源：B 站搜"Excel 数据透视表""Power Query 教程"，免费课程质量足够；书可以买一本《Excel 数据处理与分析》之类的实操作者书（几十块）。

练法：直接拿你工作里的对账表、订单表来练，学完透视表就把手头一张手工汇总表改成透视表版本。

### 阶段二：SQL（第 2–4 个月）

目标：SQL 是数据分析师岗位出现频率最高的硬技能，招聘要求里几乎 100% 有它，**这个阶段是整个路线的核心，必须练到熟练**。

学这些：
- SELECT、WHERE、GROUP BY、HAVING、ORDER BY
- 多表连接（JOIN）、子查询、窗口函数（ROW_NUMBER、RANK 等，面试常考）
- 简单的建表和导入导出

资源：
- B 站免费入门课（搜"SQL 零基础"），配 MySQL 本地安装，或直接用在线环境
- 《SQL 必知必会》（很薄，适合每天 1 小时的节奏）
- 刷题：牛客网 SQL 题库（免费）、LeetCode 数据库题，**每天保持 1–3 题，比看课重要**

### 阶段三：统计基础 + 业务思维（第 4–6 个月，和 SQL 后半段可以并行）

目标：分析师和"取数机器"的区别就在这里。

学这些：
- 描述统计：均值、中位数、方差、分位数，知道什么场景该用哪个
- 概率基础、假设检验的直觉（不要求会推导公式，要求能看懂结论）
- 常见业务分析框架：漏斗分析、留存分析、RFM 用户分层、同比环比、AB 测试的概念

资源：B 站"可汗学院统计学"或国内大学的公开统计课；业务框架可以看一些数据分析公众号、案例文章，不必专门买课。

练法：结合贸易业务给自己出题，比如"分析过去一年订单的季节性波动""客户的复购情况如何"。

### 阶段四：Python 数据分析（第 6–9 个月）

目标：会 Python 不是为了当程序员，是为了处理 Excel 撑不住的数据量和做自动化。

学这些：
- Python 基础语法（变量、循环、函数、列表字典）——大约 3–4 周
- **pandas**（核心，数据清洗、合并、分组聚合，对应你熟悉的 Excel 操作但强得多）
- matplotlib / 基础可视化
- 会用 Jupyter Notebook

资源：
- B 站免费 Python 入门课任选一套口碑好的
- 《利用 Python 进行数据分析》（pandas 作者写的，经典）
- 练法：把之前用 Excel 和 SQL 做过的分析，用 pandas 重做一遍，体会差异

注意：如果时间实在紧张，Python 可以放到入职后再深化，**SQL + Excel + 业务思维 + 一个 BI 工具就够投很多初级岗位了**。

### 阶段五：可视化 + 作品集 + 求职（第 9–12 个月）

目标：把学的东西包装成拿得出手的东西。

- **BI 工具**：选一个学透。推荐 **Power BI**（免费桌面版，国内企业用得多），或 Tableau Public（免费，作品展示方便）。
- **作品集**：做 2–3 个完整项目，理想配置是：
  1. 一个用你贸易公司真实数据（脱敏后）做的业务分析报告——这是别人抄不来的
  2. 一个用公开数据集做的完整分析（提问 → 取数 → 清洗 → 分析 → 结论建议）
  3. 一个带交互的 BI 看板
- **简历与投递**：瞄准"初级数据分析师""商业分析师（初级）""数据运营""报表专员"这类岗位；先投和贸易、供应链、电商相关的行业，你的背景就是加分项。
- 面试会考 SQL 上机题和一道业务案例分析，前两个阶段打的基础就是为这一刻准备的。

## 预算怎么花（总计约 1000–2000 元）

| 项目 | 花费 |
|---|---|
| B 站 / 牛客网 / 公开课等免费资源 | 0 元 |
| 书 4–5 本（SQL、统计、Python、Excel） | 约 300–400 元 |
| 一门质量好的付费课（可选，用来省时间，选几百块的，别上万） | 500–1500 元 |
| Power BI / MySQL / Python 全部免费 | 0 元 |

**强烈不建议报"包就业"高价训练营**。几千到几万的承诺式培训水很深，你按上面的免费资源路线走，效果不会差，试错成本低得多。

## 每天怎么安排 1–2 小时

- 工作日：工作日 1–1.5 小时，周末每天 2–3 小时补实操和刷题。
- 一个通用配方：**30 分钟学新内容 + 45–60 分钟动手练（刷题或做项目）**。看视频的占比永远不要超过一半，数据分析是练出来的。
- 允许自己有低谷期：学 SQL 的第 3–6 周和学 pandas 的前两周是最容易放弃的坎，觉得难是正常的，卡住了就多刷几道题再回去看。

## 最后几句实话

1. 10–12 个月是有纪律执行的前提下做到的，断断续续就会变成两年，**坚持比强度重要**。
2. 不要追求"学完再找"，学到阶段三结束时就可以开始看招聘要求、投几份简历试试水，用真实市场反馈校准方向。
3. 你的终局竞争力是"**懂贸易业务的数据分析师**"，而不是"会写代码的人"。技术工具会一直更新，业务理解才是你 30 岁转行真正的护城河。
