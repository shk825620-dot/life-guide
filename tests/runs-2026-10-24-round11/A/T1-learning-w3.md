# 30 岁行政转行数据分析：学习路线规划

先说结论：你的条件（有 Excel 底子、有真实业务场景、每天能挤 1-2 小时）完全够走通"业务数据分析"这条路。核心策略是 **Excel 深化 → SQL → 统计与业务思维 → BI 工具 → Python（pandas）**，全程以"做出作品集"为目标，而不是囤课囤证书。按下面的节奏，8-10 个月可以到能投简历的水平，总花费可以控制在 1000-3000 元，几千块预算绰绰有余。

---

## 一、总体时间线（约 8-10 个月）

| 阶段 | 时间 | 内容 | 产出 |
|------|------|------|------|
| 1 | 第 1 个月 | Excel 进阶 | 把手头报表重做成自动化版本 |
| 2 | 第 2-3 个月 | SQL | 刷完 150-200 道题 |
| 3 | 第 4-5 个月 | 统计基础 + 分析思维 | 1 篇业务分析笔记 |
| 4 | 第 5-6 个月 | BI 工具（Power BI） | 1-2 个交互式仪表盘 |
| 5 | 第 6-9 个月 | Python（pandas 方向） | 用 Python 重做 1 个完整分析 |
| 6 | 第 9-10 个月 | 作品集 + 求职 | 2-3 个项目 + 简历 |

每天 1-2 小时的节奏建议：**工作日输入（看课/看书 1 小时），周末输出（做练习/做项目 2-3 小时）**。转行学习最容易死在"只看不练"，务必每周都有产出物。

---

## 二、各阶段具体安排

### 阶段 1：把 Excel 用深（第 1 个月）

你已经有基础，这一步是"补齐"而不是"入门"：

- **必学**：数据透视表（重中之重）、VLOOKUP / XLOOKUP、SUMIFS / COUNTIFS、IF 嵌套、文本和日期函数、条件格式
- **图表规范**：什么数据用什么图（趋势用折线、构成用堆积柱、对比用条形），学会把一张"大表"讲成一个"结论"
- **资源**：B 站免费 Excel 教程足够，成本接近 0
- **实践**：把行政工作中的表格（库存、订单、报销、考勤……任何一张）用透视表 + 函数重做一遍，做成"更新数据就自动出结果"的版本。这个以后可以直接写进简历

### 阶段 2：SQL——最重要的硬技能（第 2-3 个月）

招聘 JD 里出现率最高的技能就是 SQL，而且对新手非常友好，语法像"填空题"，是你没有编程经验情况下最合适的第一个"编程"技能。

- **学什么**：SELECT、WHERE、GROUP BY、HAVING、多表 JOIN、子查询，进阶学窗口函数（ROW_NUMBER、SUM OVER）
- **在哪练**：牛客网 SQL 题库（免费，国内面试题风格）、SQLZOO、LeetCode 数据库题
- **目标**：累计刷 150-200 题，做到中等难度题不看答案能写出来
- **资源**：书买一本《SQL 必知必会》或《SQL 基础教程》（几十块），视频 B 站免费课即可

### 阶段 3：统计基础 + 业务分析思维（第 4-5 个月）

这一阶段决定你面试能不能"聊得出来"，比工具更重要。

- **统计就学这些**：均值/中位数/分位数、方差与波动、常见分布的直觉理解、相关不等于因果。不要陷入概率论深水区
- **分析思维**：对比分析（同比/环比）、维度拆解（销售降了，是哪个区域、哪个品类、哪个客户群）、漏斗分析、留存、A/B 测试的基本概念
- **书**：《谁说菜鸟不会数据分析》（非常贴合转行人群）或《深入浅出统计学》
- **实践**：拿一个你熟悉的问题写一篇分析笔记，比如"我们公司某类产品近一年销量变化的原因拆解"。工具可以就用 Excel

### 阶段 4：BI 工具——推荐 Power BI（第 5-6 个月）

- **为什么选 Power BI**：桌面版免费、中文资料多、国内岗位接受度高（Tableau 外企多，FineBI 国内企业多，学一个其他的能触类旁通）
- **学什么**：数据导入与清洗（Power Query）、简单的数据建模（事实表 + 维度表）、DAX 基础度量值（SUM、CALCULATE）、做交互式仪表盘
- **产出**：1-2 个完整的 dashboard，主题选贸易业务场景，比如"订单交付分析看板""客户区域销售看板"

### 阶段 5：Python——只学分析需要的部分（第 6-9 个月）

Python 是加分项不是门槛，放在后面学是对的。**只学数据分析这一条线**：

- **第 1 步（2-3 周）**：Python 基础语法——变量、列表、字典、循环、函数，够用即止
- **第 2 步（核心）**：pandas——读取文件、筛选、分组汇总（groupby）、合并（merge）、缺失值处理。你会发现它就是"代码版的透视表"
- **第 3 步**：matplotlib / seaborn 画图
- **环境**：Anaconda + Jupyter Notebook，全部免费
- **书/课**：《利用 Python 进行数据分析》、B 站免费 pandas 教程
- **明确不学**：爬虫、机器学习、算法、计算机理论——转行初期用不上，别被带偏

### 阶段 6：作品集 + 求职（第 9-10 个月）

- **做 2-3 个项目**，优先用你贸易公司的真实场景（数据脱敏）：
  - 订单/销售分析：季节性、品类结构、客户集中度
  - 客户分析：复购率、RFM 分层
  - 供应商分析：交付准时率、价格波动
  - 汇率波动对采购成本/毛利的影响（贸易公司特色，面试很加分）
- **每个项目的呈现结构**：业务背景 → 数据来源与清洗 → 分析过程 → 结论 → 可执行建议
- **简历包装**：把行政经历往数据方向靠——"搭建部门报表体系""用透视表将月度对账时间从 X 小时缩短到 Y 分钟""自学 SQL/Power BI 并完成 XX 分析项目"
- **路径优先级**：① 内部转岗（先在现公司主动承担业务报表、运营分析类工作，最平滑）② 投贸易/零售/快消行业的业务数据分析师岗（你的行业背景是优势）③ 再考虑纯互联网数据岗

## 四、避坑提醒

1. **不要一上来报上万元的培训班**。你的时间结构（在职、每天 1-2 小时）和预算更适合"免费/低价资源 + 自驱项目"的模式，大班课不适配在职学习节奏。
2. **不要陷入工具收集癖**。SQL 是优先级最高的单项技能，先吃透它；Excel 和 SQL 熟练就已经能胜任一部分初级岗位。
3. **统计够用就行**，目标是"用数字讲故事"，不是考研。
4. **每个阶段必须有产出物**。学完不做项目等于白学，作品集才是转行的敲门砖。
5. **瞄准"业务数据分析"岗**，不要直接冲"数据挖掘/算法"岗——前者重业务理解和报表能力，正好匹配你的背景，也是转行命中率最高的方向。
6. **不要裸辞学习**。边工作边学 + 内部争取数据类任务，是最稳的路径；30 岁转行不晚，一年后你才 31，带着"行政 + 数据"复合背景反而比应届生更有行业竞争力。
