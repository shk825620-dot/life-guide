# 减少信息差（life-guide）

> 很多时候，难点不只是从几个选项里挑一个，而是一开始只看见了几个选项。

“我想做个小生意”常被直接带到奶茶、咖啡或服装店，却漏看原料耗材、杯和吸管、设备、配送、维修等不同参与位置；“想 1:1 仿一个网站”也可能在写代码之前就有现成工具或成熟做法可查。它们只是值得调查的方向，不代表已证明有需求或适合每个人。

life-guide 是一套面向 Agent Skills 兼容宿主的通用研究与决策 Skill。它帮助 AI 先了解用户要解决的问题，再寻找现成方案、不同路线、适用规则和可能遗漏的前提，核对重要事实后按现实条件比较并给出行动步骤。

## 它会做什么

- 关键目标或条件会改变个人建议时，先问清楚再研究；信息已充分时直接办事。
- 检查候选从哪里来，按问题寻找不同解决形态、参与位置和进入路径，不为凑数穷举。
- 查成熟工具和可复用做法，核对来源、时效、适用对象、规则门槛和例外。
- 依据用户已说明的条件筛选，给主推荐、有意义的备选、取舍、未知和可执行下一步。
- 可按用户选择进入快速决断（约 30 分钟投入拿首个可行动检查点）或重大决策（约 3 小时内分阶段深入）；两者都把机会成本、相对耗时和稳健性说清。
- 重要选择按需检查现有关系能打开的其他路线、可比案例、关键假设和失败信号；社交平台用于发现线索，真实使用或交易行为用于验证需求。
- X、微博、小红书和教程只作为可分级核查的线索；需要工具时先核对来源、权限和账号风险，由用户明确批准安装，不能把评分写成无病毒或不封号保证。
- 复杂问题按需使用五类专题研究角色：选项空间、成熟方案、主张与时效、规则与例外、现实可行性。
- 如实区分事实、用户信息、推断与未知；有依据时可以反对，也会根据新证据改判。

## 使用

`skills/life-guide/` 是本仓库的标准 Agent Skills 源包。将该目录安装到支持 Agent Skills 的宿主，并在实际宿主中确认加载情况。各产品对格式、工具、子 Agent 和自动触发的支持不同；本仓库当前没有宣称全部宿主已经实测兼容。

## 安装与加载

1. 把 `skills/life-guide/` 整个目录复制进宿主的技能目录（目录名保持 `life-guide`），不要只复制 `SKILL.md`——参考文件按需读取，缺了规则就不可达。
2. 在宿主中确认技能已被识别（能列出名称与描述）；宿主对触发、参考文件读取和子 Agent 的支持各不相同。
3. 首次使用时用一个你熟悉答案的问题试一次，核对回答是否先问关键条件、是否标注来源与日期。
4. 宿主缺少联网检索时技能仍可用，但外部事实只能标"未核实"；缺少多轮对话时按技能内置的降级规则给条件化结论。
5. 宿主专属字段（展示名、本地化描述、作者等）按 `adapters/` 的说明单独生成，不回写核心包。**当前标准包为 6.0.1；WorkBuddy 目标目录仍残留旧参考文件；自动触发和安装后行为未实测，未实测的宿主一律视为未验证。**

商业测算的行为标准见 [`tests/acceptance-criteria-business-2026-10-22.md`](tests/acceptance-criteria-business-2026-10-22.md)（新增标准，不回填历史通过）；4.0.4→4.0.5 的同条件对比与迁移案例见 [`tests/round-2026-10-22.md`](tests/round-2026-10-22.md)，被测副本冻结记录见 [`tests/frozen-baseline-2026-10-22.md`](tests/frozen-baseline-2026-10-22.md)。**校验器通过只证明包结构与格式，不证明业务结论正确。**

本机测试均为手动加载候选内容或本地校验，不是 WorkBuddy 自动触发或安装后实测。WorkBuddy 目录与当前 6.0.1 源包不一致且仍有旧文件残留；仓库已加入 MIT 许可证。
